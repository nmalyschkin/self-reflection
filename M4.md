## M4 — UX polish & safety

Goal: Improve clarity and control of the AI workflow, add tagging/pinning for organization, and offer optional client-side encryption for privacy.

Definition of Done

- [ ] Prompt template is editable by the user (with sensible defaults)
- [ ] Tagging and pinning implemented; filters for pinned and by tag
- [ ] Optional encryption-at-rest for entry content using a passphrase

Step-by-step Tasks

- [ ] 1. Prompt tuning

  - [ ] Create a settings area (modal or page) with a text area for the prompt template
  - [ ] Default template includes placeholders like `{{text}}` and guidance style
  - [ ] Validate template minimally; on save, persist to storage
  - [ ] When summarizing, render template with the current entry text

- [ ] 2. Tagging and pinning

  - [ ] Extend `Entry` type: `tags: string[]` and `pinned: boolean`
  - [ ] Add tag editor (comma-separated input or chips)
  - [ ] Add a pin toggle on list and details
  - [ ] Filters: show pinned first; basic tag filter UI

- [ ] 3. Optional encryption

  - [ ] Add a setting: "Encrypt entries with a passphrase" (opt-in)
  - [ ] On enable, prompt for passphrase and confirm; derive key with Web Crypto (PBKDF2 or HKDF)
  - [ ] Encrypt new entries' sensitive fields (text, summary, questions) before persisting
  - [ ] For existing entries, offer a one-time migration
  - [ ] Store only a salted hash or an encrypted blob; never store the raw passphrase
  - [ ] On app load, if encryption is enabled, request passphrase to unlock

- [ ] 4. Manual QA

  - [ ] Editing prompt changes AI outputs as expected
  - [ ] Tagging/pinning visible in list and filter works
  - [ ] With encryption enabled, entries are unreadable in devtools storage view
  - [ ] Wrong passphrase fails gracefully without data loss

- [ ] 5. Final verification
  - [ ] All "Definition of Done" items are checked
  - [ ] Encryption opt-in documented; recovery limitations explained
  - [ ] Tags/pins and filters behave consistently after reload
  - [ ] Commit and tag release (e.g., m4)

Notes

- Keep UX simple; avoid overwhelming with settings
- Document that encryption is optional and passphrase recovery is impossible
