## M5 — Extensible tools sidebar

Goal: Introduce a sidebar that can host additional tools. Implement the first tool: cross-entry summarizer.

Definition of Done

- [ ] Sidebar component that can contain multiple tool panels
- [ ] Simple plugin interface or registry for tools (id, title, component)
- [ ] Cross-entry summarizer tool that batches selected entries and produces an overview

Step-by-step Tasks

- [ ] 1. Sidebar shell

  - [ ] Create a collapsible sidebar layout with Tailwind
  - [ ] Add tabs or a list to switch between tools

- [ ] 2. Tool registry

  - [ ] Define a `ToolDescriptor` type (id, title, render)
  - [ ] Maintain a registry array and render active tool by id
  - [ ] Provide a minimal API to register tools

- [ ] 3. Cross-entry summarizer tool

  - [ ] UI: list entries with checkboxes; select multiple
  - [ ] Button: "Summarize Selected"
  - [ ] Build a prompt that:
    - [ ] Summarizes themes across selected entries
    - [ ] Outputs key insights and suggested follow-up questions
  - [ ] Use Prompt API; if unavailable, show a helpful message

- [ ] 4. Performance & UX

  - [ ] Limit max characters per batch; show character count
  - [ ] Add loading state and cancellation

- [ ] 5. Manual QA

  - [ ] Selecting multiple entries and summarizing produces reasonable output
  - [ ] Registry can host at least one more dummy tool

- [ ] 6. Final verification
  - [ ] All "Definition of Done" items are checked
  - [ ] Another tool can be added via registry without code changes to shell
  - [ ] Commit and tag release (e.g., m5)

Notes

- Keep the plugin surface small; avoid complex lifecycle hooks initially
