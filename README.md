# Reflect

https://self-ref.web.app/

Basic instructions to run the app locally.

## Prerequisites

- Node.js 18 or newer
- npm 10 or newer (comes with recent Node versions)

## Quick start

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## Build for production

```bash
npm run build
npm run preview
```

This will serve the production build locally so you can verify it.

## Useful scripts

- `npm run dev`: Start the Vite dev server
- `npm run build`: Type-check and build the app
- `npm run preview`: Preview the production build
- `npm run lint`: Run ESLint
- `npm run format`: Run Prettier to format files

## Tech stack

- Vite + React + TypeScript
- Chakra UI
- TipTap (editor)
- i18next (localization)
